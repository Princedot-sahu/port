# Prince Sahu - Personal Portfolio Web Application

A modern, responsive React portfolio application built using modern visual design principles (Glassmorphism, high-contrast dark theme, fluid typography, visual hierarchy, and accessibility).

## 🚀 Quick Start Guide

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your system.

### Steps to Run
1. Unzip the downloaded file and open a terminal inside the project directory:
   ```bash
   cd prince-sahu-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm start
   ```

4. Open your browser and navigate to `http://localhost:3000`.

## 🛠️ Tech Stack & Design Features
- **Frontend Framework:** React 18
- **Icons:** Lucide React (`lucide-react`)
- **Animations:** Framer Motion (`framer-motion`)
- **Theme:** Dark Mode Glassmorphism with modern CSS typography & color variables
- **Layout:** Fully responsive multi-section layout (Hero, About, Skills, Projects, Education, Contact)
